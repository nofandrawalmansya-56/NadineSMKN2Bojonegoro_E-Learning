Konsep Dasar Sistem Operasi, Manajemen Memori & Proses

Pelajari bagaimana sistem operasi bertindak sebagai jembatan antara perangkat keras dan perangkat lunak, mengelola eksekusi proses CPU, serta mengalokasikan ruang memori secara efisien.

BAB 6 – Laboratorium Praktikum & Observasi Sistem

Panduan langkah demi langkah praktikum eksperimen langsung mengamati manajemen proses, alokasi memori, dan performa komputer.

Praktikum #1

Observasi Proses Menggunakan Task Manager / Activity Monitor

Tujuan: Mengidentifikasi status proses, PID (Process ID), penggunaan CPU, dan memori RAM yang digunakan oleh aplikasi yang sedang berjalan secara real-time.

Langkah Kerja:

  1. Buka Task Manager (`Ctrl + Shift + Esc`) pada Windows atau Activity Monitor pada macOS.
  2. Pilih tab Processes atau Details.
  3. Urutkan aplikasi berdasarkan konsumsi Memori (RAM) tertinggi.
  4. Buka peramban web (Chrome/Edge) dengan 5 tab baru, lalu amati kenaikan konsumsi RAM.
Praktikum #2

Manajemen Proses via Command Line (CLI / Terminal)

Tujuan: Mempraktikkan perintah dasar sistem operasi untuk melihat, menghentikan (kill), dan memprioritaskan proses via CLI.

# Menampilkan daftar proses di Linux/macOS:

$ ps aux | grep python

# Menghentikan proses berdasarkan PID:

$ kill -9 4821

# Menampilkan proses di Windows CMD:

C:\> tasklist /FI "MEMUSAGE gt 50000"
